# 九路陪练

围棋教学 App：KataGo 引擎在手机本地运行（GPU 优先，失败自动用 CPU），DeepSeek 负责把引擎的判断讲成人话。

- 9 / 13 / 19 路，人机对局（按段位模仿人类，胜负自动升降级）和双人对局
- 招式卡：招式名 + 位置 + 原因 / 作用 / 建议
- 招式等级：神之一手、妙手、手筋、好棋；缓手、俗手、恶手、败着
- 半透明棋子演示正解和变化，术语本，战绩，朗读

## 打包
推送到 `main` 分支后，GitHub Actions 自动编译 KataGo、下载模型、打包 APK，并发布到 Releases。

## 目录
- `app/src/main/assets/www/`：界面和对局逻辑（网页）
- `app/src/main/java/`：安卓外壳（引擎进程、网络请求、朗读）
- `scripts/`：编译 KataGo、下载模型
